# Live News Sentiment Analysis

A Streamlit dashboard that fetches current English news headlines from NewsAPI and analyzes their sentiment with TextBlob.

## Features

- Search news by topic.
- Start with common technology and finance topics such as AI, Bitcoin, Tesla, and NVIDIA.
- Add custom topics from the sidebar.
- Choose how many articles to analyze.
- Classify headlines as positive, negative, or neutral.
- View sentiment counts, a sentiment distribution chart, and polarity distribution.
- Open the original article from the dashboard.
